# Microsoft Azure AZ-104 Projects

This repository contains a collection of hands-on Microsoft Azure projects and labs designed to build practical skills for the **Microsoft Azure Administrator (AZ-104)** certification.

The goal of this repository is to learn Azure administration by actually building, configuring, testing, and troubleshooting Azure environments rather than relying only on theoretical study.

Each project focuses on different Azure services and administrative concepts covered throughout the AZ-104 learning path.

---

# Repository Goals

The main goals of these projects are to:

- Build practical Microsoft Azure administration experience
- Prepare for the AZ-104 certification
- Learn how Azure services work together
- Practice identity and access management
- Configure and manage Azure resources
- Apply security and least-privilege principles
- Practice Azure networking and storage
- Manage compute resources
- Automate administrative tasks
- Troubleshoot Azure environments
- Document technical work using GitHub

---

# Projects

Each project is contained in its own directory and includes documentation explaining what was built, how it was configured, what was tested, and what was learned.

## Project 01 — Enterprise Azure Identity & RBAC Lab

A hands-on identity and access management lab focused on:

- Microsoft Entra ID
- Users
- Security Groups
- Azure Resource Groups
- Azure RBAC
- Role Assignments
- RBAC Scope
- Least Privilege
- Permission Testing
- Authorization Troubleshooting

The lab involved creating different users and groups, organizing Azure resources into resource groups, assigning RBAC roles, and testing the permissions using separate accounts.

# Learning Approach

These projects are designed around a **build → test → troubleshoot → document** approach.

Rather than simply following instructions and moving on, I am focusing on understanding why each configuration is being used and what happens when permissions, settings, or resources are changed.

The general process is:

```text
Learn the Concept
       ↓
Build the Environment
       ↓
Configure Azure
       ↓
Test the Configuration
       ↓
Troubleshoot Problems
       ↓
Document the Results
       ↓
Apply the Knowledge to the Next Project
```
